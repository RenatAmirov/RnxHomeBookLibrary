# Книжная полка

Локальная домашняя библиотека с каталогом, поиском по темам и учётом выдач.

## Запуск

Нужен Node.js 22.13 или новее. Из папки проекта выполните `npm.cmd start` в PowerShell или `npm start` в другом терминале. Откройте [библиотеку](http://127.0.0.1:3000). Установка пакетов не требуется.

## Работа с каталогом

- В режиме ребёнка доступны поиск по названию, автору и теме, фильтры и карточки книг.
- При первом входе в режим родителя задайте PIN из 4–12 цифр. В этом режиме можно добавлять книги, выдавать их читателям и отмечать возврат.
- Каждая карточка соответствует одному экземпляру. Если у вас два одинаковых экземпляра, добавьте по карточке для каждого.
- При первом запуске есть четыре книги для примера. Убрать их можно внизу каталога в режиме родителя. Пример книги сохранится, если вы уже оформили для него собственную выдачу.

Книги, выдачи и настройки хранятся в `data/library.sqlite`. Для резервной копии остановите сервер и скопируйте папку `data`.
